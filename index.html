CloudTuner Kubernetes Helm Charts

Official Helm repository for CloudTuner Kubernetes cost metrics collector

🚀 Quick Installation

Install using our one-liner script:

curl -fsSL https://invinciblecodes.github.io/k8s-helm-chart/install.sh | bash

📦 Manual Installation

Add the Helm repository and install:

# Add repository
helm repo add cloudtuner https://invinciblecodes.github.io/k8s-helm-chart

# Update repositories
helm repo update

# Install the chart
helm install kube-cost-metrics-collector cloudtuner/kube-cost-metrics-collector

🔧 Configuration

Customize your installation with values:

# Create custom values file
cat > my-values.yaml << EOF
prometheus:
  server:
    persistentVolume:
      enabled: true
      size: 10Gi
EOF

# Install with custom values
helm install kube-cost-metrics-collector cloudtuner/kube-cost-metrics-collector -f my-values.yaml
