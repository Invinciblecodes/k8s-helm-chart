CloudTuner Kubernetes Cost Metrics Collector

Deploy the collector to send Kubernetes pod cost metrics to your CloudTuner account.

Quick Install

Run the one‑liner installer:

curl -fsSL https://invinciblecodes.github.io/k8s-helm-chart/install.sh | bash

Helm Installation

Add the repo, update, and install with your credentials.

helm repo add cloudtuner-k8s https://invinciblecodes.github.io/k8s-helm-chart/
helm repo update
helm install kube-cost-metrics-collector cloudtuner-k8s/kube-cost-metrics-collector \
  --set prometheus.server.dataSourceId=<YOUR_DATA_SOURCE_ID> \
  --set prometheus.server.username=<USERNAME> \
  --set prometheus.server.password=<PASSWORD> \
  --namespace cloudtuner-k8s --create-namespace
Replace <YOUR_DATA_SOURCE_ID>, <USERNAME>, and <PASSWORD> with the values provided by CloudTuner. Metrics begin appearing in your dashboard within ~1 hour after install.
